# Community code of conduct

We want DSH Ocean's issues, pull requests and other project spaces to be useful,
respectful and welcoming to contributors of every background and experience level.
This policy also applies when representing the project in other spaces.

## Expected behavior

- Be considerate and constructive; critique ideas and code, not people.
- Assume good faith, ask questions and explain technical disagreements with evidence.
- Respect different experiences, accessibility needs and reasonable boundaries.
- Accept correction, take responsibility for mistakes and protect others' privacy.

Harassment, discriminatory insults, sexualized attention, threats, sustained
personal attacks, deliberate disruption, impersonation and publication of private
information without consent are not acceptable. Good-faith disagreement or a
respectful technical rejection is not itself a conduct violation.

## Reporting

Do not publish sensitive evidence, private communications or identifying details
in a public report. Contact a repository maintainer using a private channel they
have explicitly advertised. If none is available, request a private contact in an
issue without disclosing the incident. For a security vulnerability instead, use
[SECURITY.md](SECURITY.md). GitHub platform abuse can also be reported through
GitHub's own reporting tools, particularly if a concern involves a maintainer.

A dedicated confidential conduct contact has not yet been established. Maintainers
must establish one before soliciting sensitive incident details; do not assume an
arbitrary Git author address is such a channel.

## Enforcement

Maintainers may edit/remove inappropriate content, warn participants, temporarily
restrict participation or permanently block serious/repeated misconduct. They
should consider severity, context and impact, use proportionate measures, explain
decisions when safe, and avoid retaliation against good-faith reporters. Share
reports only with people necessary to handle them; absolute confidentiality
cannot be promised on third-party platforms.

A participant may request reconsideration privately with new context. A maintainer
involved in an incident should not be the sole decision-maker when an uninvolved
reviewer is available. This small project has no independent appeals board.
